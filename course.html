Chapter 1 — What is HTML? 🌱Beginner

HTML (HyperText Markup Language) is the standard language for creating web pages. "HyperText" means text that contains links to other text, and "Markup" means tagging content so the browser knows what each part means.

How a website works: you write HTML in a file, the browser reads the file and renders it visually. HTML describes structure, CSS describes style, JavaScript describes behavior. These are the three core languages of the web.

<!DOCTYPE html>
<html>
  <head>
    <title>My Page</title>
  </head>
  <body>
    <h1>Hello World!</h1>
    <p>My first paragraph.</p>
  </body>
</html>

Parts of the structure: <!DOCTYPE html> tells the browser this is HTML5. <html> is the root element. <head> holds invisible information like the title. <body> holds everything the user sees. Tags usually come in pairs — opening tag and closing tag with a /.

💡 Every website you have ever visited — Google, WeChat Web, YouTube — is built with HTML.
📝 Practice: Open Notepad, type the code above, save it as mypage.html, then double-click it. Congratulations — you just made your first web page!
Chapter 2 — Text, Links & Images ✍️Beginner

Headings run from <h1> (biggest) to <h6> (smallest). Use only one <h1> per page. Paragraphs use <p>. Links use <a href=""> — the "hyper" in hyperText. Images use <img src="">.

<a href="https://www.w3schools.com">Visit W3Schools</a>
<a href="page2.html">Relative link to my own page</a>
<a href="#section1">Jump inside this page</a>
<img src="photo.jpg" alt="A description of the image" width="300">
<b>Bold</b> · <i>Italic</i> · <mark>Highlighted</mark> · <small>Small</small>

Two kinds of links: absolute links contain a full URL (https://…) and go to other websites. Relative links point to files in your own project folder. Anchor links with # jump within the same page.

💡 Always add the alt attribute to images — it helps blind users and improves your grade on accessibility.
📝 Practice: Create a page with an h1 title, a paragraph about your hometown, a photo, and a link back to your school's website.
Chapter 3 — Lists & Tables 📋Beginner

Three types of lists: unordered <ul> (bullet points), ordered <ol> (numbered), and description lists <dl> (term + definition pairs).

<ul>
  <li>Apple</li>
  <li>Banana</li>
</ul>

<ol start="3" type="A">
  <li>Step C</li>
</ol>

<table>
  <caption>Class Roster</caption>
  <tr><th>Name</th><th>Age</th></tr>
  <tr><td>God Eger</td><td>20</td></tr>
</table>

Table anatomy: <table> wraps everything, <tr> is a row, <th> is a header cell (bold, centered), <td> is a data cell, <caption> names the table.

💡 Use tables for real grid data like timetables and prices — not for page layout. Layout is CSS's job.
📝 Practice: Build a weekly class timetable as a table with days as columns and subjects as rows.
Chapter 4 — Forms & Input 📬Intermediate

Forms collect user data — logins, search bars, contact pages, surveys.

<form action="/submit" method="post">
  <label>Name: <input type="text" name="name" required></label>
  <label>Email: <input type="email" name="email"></label>
  <label>Age: <input type="number" min="1" max="120"></label>
  <label><input type="radio" name="gender" value="m"> Male</label>
  <label><input type="checkbox" name="ok"> I agree</label>
  <select><option>China</option><option>Other</option></select>
  <textarea rows="3"></textarea>
  <input type="submit" value="Send">
</form>

method "get" appends data to the URL (for searches) while "post" sends it hidden (for logins). The name attribute is what the server receives; required blocks empty submission.

💡 HTML5 input types: email, number, date, range, color, file, tel — the browser does validation for free!
📝 Practice: Build a "Student Registration" form with name, email, date of birth, country dropdown and a submit button. Try submitting empty — the browser should stop you.
Chapter 5 — Semantic HTML5 🧩Intermediate

HTML5 introduced semantic tags that describe the meaning of content instead of just grouping it:

<header>  — top of page, logo & nav
<nav>     — navigation links
<main>    — main unique content (only one per page!)
<section> — a grouped topic section with heading
<article> — self-contained post or news item
<aside>   — sidebar or related content
<figure>  — image with caption <figcaption>
<footer>  — bottom of page, credits

section vs article: a <section> is a thematic grouping that belongs to the page; an <article> makes sense on its own, like a blog post or product card. Use <div> only when no semantic meaning applies.

💡 Semantic tags are loved by teachers, employers, and Google — they replace the old "div soup" and improve SEO and screen-reader support.
📝 Practice: Rebuild your Chapter 1 page using header, nav, main, section and footer.
Chapter 6 — Multimedia: Audio, Video & Canvas 🎬Intermediate
<video src="movie.mp4" controls autoplay muted loop poster="cover.jpg"></video>
<audio src="song.mp3" controls></audio>
<iframe src="https://www.youtube.com/embed/VIDEO_ID" width="560" height="315"></iframe>
<canvas id="draw" width="400" height="200"></canvas>

HTML5 ended the Flash era — native video/audio with controls. MP4 (H.264) for video and MP3 for audio are supported everywhere. autoplay requires muted in modern browsers.

The <canvas> tag is a blank drawable surface controlled by JavaScript — the routine chart on this site is drawn with it. Canvas draws pixels; SVG draws shapes that scale infinitely.

💡 Provide multiple sources with <source> inside video/audio so every browser finds a format it can play.
📝 Practice: Embed a video, an audio file, and a YouTube video on one page using an iframe.
Chapter 7 — Entities, Escaping & Advanced Tables 🔣Intermediate

Some characters are special because they are part of HTML syntax itself. To display them, escape them with entities:

&lt;  → shows <    &gt;  → shows >
&amp; → shows &    &quot; → shows "
&copy; → shows ©    &nbsp; → non-breaking space
&#2734; → any Unicode symbol by number code

Advanced tables: merge cells with colspan (across columns) and rowspan (down rows). Group long tables with <thead>, <tbody> and <tfoot>.

<tr><th colspan="2">Full Name</th></tr>
<tr><td rowspan="2">China</td><td>Beijing</td></tr>
   <tr><td>Shanghai</td></tr>
📝 Practice: Write "<html> rocks & rolls © 2026" so it displays exactly like that on screen.
Chapter 8 — Metadata, SEO & Web Storage ⚙️Advanced
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="A helpful study website">
  <meta name="author" content="God Eger">
  <link rel="icon" href="favicon.png">
</head>

Why these matter: charset lets you write Chinese and English together safely. The viewport meta makes sites usable on phones — without it, mobile browsers zoom out. The description meta is what Google shows under your title in search results (that is SEO — Search Engine Optimization).

HTML5 added Web Storage: localStorage persists forever, sessionStorage clears when the tab closes. This website uses it to save your progress.

localStorage.setItem("progress", "50");
localStorage.getItem("progress");
localStorage.removeItem("progress");
sessionStorage.setItem("temp", "gone later");
📝 Practice: Write a page that asks the visitor's name once, saves it with localStorage, and greets them by name on every return visit.
Chapter 9 — Accessibility & Performance 🦾Advanced
💡 Accessibility (a11y) = making the web usable for everyone, including blind, deaf and disabled users. Many countries legally require it.

Accessibility rules: every image needs alt, every input needs a <label>, use aria-label for icon-only buttons, keep heading order logical (one h1, then h2…), ensure color contrast of at least 4.5:1, and make everything keyboard-operable with tabindex.

<button aria-label="Close dialog">✕</button>
<img src="chart.png" alt="Study hours increased by 20% in October">
<html lang="en">

Performance rules: compress images, load scripts with defer, lazy-load below-the-fold images, use modern formats like WebP.

<script src="app.js" defer></script>
<img src="photo.webp" loading="lazy" alt="...">
📝 Practice: Open your own page using only the keyboard — no mouse. Can you reach every button and link with Tab? If not, fix it.
Chapter 10 — HTML5 APIs & Modern Web 🔮Expert

HTML5 is more than tags — it ships with powerful JavaScript APIs built into the browser:

  • Geolocation — find the user's location
  • Drag & Drop — draggable elements and file uploads
  • Web Workers — background processing without freezing the page
  • History API — change the URL without reloading
  • Canvas + WebGL — games and 3D graphics
  • WebSockets — real-time two-way communication for chat apps
  • Service Workers — offline web apps, the engine behind PWAs
  • Notifications & Vibration — system-level alerts
navigator.geolocation.getCurrentPosition(pos =>
  console.log(pos.coords.latitude, pos.coords.longitude));

const ws = new WebSocket("wss://example.com/chat");
ws.onmessage = e => console.log("New:", e.data);

Modern expert workflow: validate with the W3C validator, test with DevTools (F12), use responsive design mode, deploy free on GitHub Pages or Netlify, follow progressive enhancement — the site works even if JavaScript fails.

💡 After mastering HTML5, continue with CSS (Flexbox/Grid), then JavaScript — that path is called "front-end developer". Then frameworks like React or Vue.
