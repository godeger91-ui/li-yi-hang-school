📖 The Story of Li Yi Hang Learning

Li Yi Hang Learning started as a class project: as international students in China, we wanted one simple, colorful place to learn HTML5 and organize our study life — in English, with everything a beginner needs in a single website. The site is built with pure HTML5, CSS and JavaScript, no frameworks, exactly the technologies it teaches.

🛠️ Technologies Used

  • HTML5 — semantic structure, multiple linked pages
  • CSS3 — CSS variables, animations, gradients, responsive grid
  • JavaScript — canvas chart, quiz engine, localStorage saving
