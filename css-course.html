Chapter 1 — What is CSS? 🎨Beginner

CSS (Cascading Style Sheets) controls how HTML looks: colors, fonts, spacing, layout, and animation. HTML is the skeleton; CSS is the skin and clothing.

Three ways to apply CSS: inline (style="" attribute), internal (<style> tag in the head), and external (<link rel="stylesheet" href="styles.css">) — the best way, used by this website.

p {
  color: #00cec9;
  font-size: 18px;
}

Anatomy of a rule: selector (what to style) + properties in { } with property: value; pairs.

💡 "Cascading" means later rules and more specific selectors override earlier ones. Order and specificity matter!
📝 Practice: Link styles.css to your HTML course practice page and change its background color.
Chapter 2 — Selectors Masterclass 🎯Beginner
p          {}   /* all paragraphs          */
.warning   {}   /* class: <p class="warning"> */
#top       {}   /* id: one unique element    */
*          {}   /* everything               */
ul li      {}   /* li inside ul (descendant) */
a:hover    {}   /* pseudo-class: on hover   */
li:first-child {}  /* structural pseudo      */
input[type="email"] {}  /* attribute selector */

Specificity ranking (who wins a fight): inline style > #id > .class > element. When two rules tie, the one written later in the file wins.

💡 Use classes for reusable styles, IDs only for unique elements, and keep selectors short — long chains become unmanageable.
📝 Practice: Style three paragraphs differently using a tag selector, a class, and an ID. Predict which one wins when you combine them.
Chapter 3 — Colors, Fonts & the Box Model 📦Beginner

Colors: named (red), hex (#00cec9), rgb/rgba (rgba(0,0,0,.5) for transparency), and HSL.

Fonts: font-family stacks with fallbacks, font-size, font-weight, line-height. Use system fonts or Google Fonts.

.box {
  background: #1b1b2f;
  color: #f5f6fa;
  font-family: 'Segoe UI', Arial, sans-serif;
  margin: 20px;      /* space OUTSIDE the border  */
  padding: 15px;     /* space INSIDE the border   */
  border: 2px solid #00cec9;
  border-radius: 15px;
}

The box model: every element is content + padding + border + margin, in that order. box-sizing: border-box makes width include padding and border — much easier for layout.

💡 Start every project with * { box-sizing: border-box; } — this site does!

Chapter 4 — Flexbox Layout 🧱Intermediate

Flexbox arranges children in a row or column and distributes space between them. This website's nav bar is flexbox!

.container {
  display: flex;
  flex-direction: row;        /* or column */
  justify-content: center;    /* main axis alignment */
  align-items: center;        /* cross axis alignment */
  gap: 20px;                  /* space between items */
  flex-wrap: wrap;
}
.item { flex: 1; }            /* grow to fill space */

justify-content values: flex-start, center, flex-end, space-between, space-around. Perfect centering is now one line: justify-content:center; align-items:center;

💡 Flexbox is for ONE direction (a toolbar, a row of cards). For two-dimensional page layout, use Grid — next chapter.
📝 Practice: Build a nav bar and a 3-card pricing row with flexbox; make cards equal height with flex:1.
Chapter 5 — CSS Grid Layout 🗺️Intermediate
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);  /* 3 equal columns */
  gap: 15px;
}
.card { grid-column: span 2; }   /* card spans 2 columns */

Responsive without media queries: repeat(auto-fit, minmax(250px, 1fr)) creates as many 250px columns as fit — cards reflow automatically. This exact line styles the card grids on every page of this site!

💡 Rule of thumb: Grid for the overall page structure, Flexbox for components inside it.

Chapter 6 — Responsive Design & Media Queries 📱Intermediate
@media (max-width: 600px) {
  body { font-size: 14px; }
  .grid { grid-template-columns: 1fr; }  /* stack on phones */
}
img { max-width: 100%; height: auto; }   /* fluid images */

The mobile-first approach: write CSS for phones first with simple styles, then add @media (min-width: ...) enhancements for bigger screens. Also set the viewport meta tag — without it, media queries fail on phones (Chapter 8 of the HTML course).

Units that scale: prefer rem (relative to root font), %, vw/vh over fixed px for layout.

💡 Resize your browser window right now and watch this website adapt — that's media queries and auto-fit grids in action.

Chapter 7 — Transitions, Transforms & Animations ✨Advanced
.card {
  transition: transform .3s, box-shadow .3s;  /* smooth change */
}
.card:hover {
  transform: translateY(-8px) scale(1.02);   /* 2D transforms */
  box-shadow: 0 15px 30px rgba(108,92,231,.4);
}
@keyframes bgShift {          /* keyframe animation */
  0%   { background-position: 0% 50%; }
  50%  { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}
header { animation: bgShift 12s ease infinite; }

Transforms: translate, rotate, scale, skew. Animation parts: animation-name, duration, timing function (ease, linear), delay, iteration count (infinite), direction.

💡 Animate only transform and opacity — they use the GPU and stay smooth. Animating width or top is slow.

Chapter 8 — CSS Variables & Theming 🌈Advanced
:root {              /* global custom properties */
  --c1: #6c5ce7;
  --card: #1b1b2f;
}
.card {
  background: var(--card);
  border-color: var(--c1);
}
@media (prefers-color-scheme: light) {
  :root { --card: #f0f0f5; }   /* automatic dark/light mode! */
}

Why variables: change one value, restyle the whole site. This entire website's color theme lives in the :root block of styles.css — swap four hex values and the branding changes everywhere.

💡 Variables cascade and can be overridden per element: .dark-card { --card: #000; } re-themes just that card.
📝 Practice: Copy this site's :root block, change --c2 to orange, and watch every accent color across all pages change.
Chapter 9 — Positioning, Z-Index & Overflow 🧲Advanced
nav  { position: sticky;  top: 0; z-index: 10; }  /* sticks on scroll */
.badge { position: absolute; top: 5px; right: 5px; }  /* inside a relative parent */
.modal { position: fixed;  inset: 0; }            /* covers the viewport */
body { overflow-x: hidden; }                      /* kill sideways scroll */

Position values: static (default), relative (offset without affecting others), absolute (pinned to nearest positioned ancestor), fixed (pinned to viewport), sticky (scrolls until a threshold, then sticks — used by this site's nav).

z-index stacks overlapping elements; higher wins, but only within the same stacking context.

Chapter 10 — Professional CSS & Real Projects 🔮Expert

Expert workflow: organize styles with a naming method like BEM (.block__element--modifier), use logical shared stylesheets (like this site's single styles.css), reset browser defaults, and audit unused CSS with DevTools Coverage.

.btn { }
.btn--primary { }
.btn--primary.is-disabled { }   /* BEM naming example */

Modern topics to explore next: CSS animations with @property, container queries (@container), :has() parent selector, subgrid, scroll-driven animations, and preprocessors/PostCSS. After that: frameworks like Tailwind or utility-first patterns.
